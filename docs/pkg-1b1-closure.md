## 2. Arabic Advisor P0 (fixed at the structured-evidence boundary)

Root cause: the value answer was generated by two separate free-text model calls (EN
and AR) from a band whose segment scope was never compared to the requested grade, so
AR could relabel the general-office band as "Grade A" and leave the location in English.

Fix: src/lib/market/valueEvidence.ts builds ONE structured result (evidence id, source,
period, localized location, asset, supported vs requested segment, unit, low/avg/high,
user figure, support status, limitation reason); both locales render from it
deterministically (no model). api/advisor value mode rewired to use it; the client
handoff label is localized.

Deterministic tests (src/lib/market/valueEvidence.test.ts, 11): EN/AR share evidence
id and supported scope; expose the same numeric set; a general-office band cannot
become a Grade A band; a missing user price never becomes a quotation; every figure
comes from evidence or user input; unsupported evidence yields the same limitation in
both languages; Arabic location localized; Western numerals kept.
